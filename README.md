How Requirements Were Addressed
Color Palette: Used Slate Navy (#1E293B) for table headers and primary text, Cyan Blue (#0EA5E9) for active buttons and links, and soft Cool Gray (#F1F5F9 / #F8FAFC) for page backgrounds and alternating table rows.

Typography: Imported Google Fonts (Poppins for clean, bold headings and Inter for highly legible body text, labels, and table content).

Table & Form Styling: Applied padding to cells and form inputs, border-collapse, a contrasting header color, alternating row colors (tr:nth-child(even)), and subtle focus states on inputs.

CSS Box Model & Cards: Applied margin-bottom between sections, internal padding, borders, and border-radius to turn the <header>, form <section>, and table <section> into self-contained visual cards with drop shadows.
